# A01 · 镜像构建（单独的镜像/target）

> 场景：改完代码要把 nx-as 打成镜像。Dockerfile 三个 target 各是一个独立镜像，按用途选。

## 三个 target（docker build --target <名>）

| target | 产物 | 用途 |
|---|---|---|
| `base` | `nx-as-base` 权限壳（nginx + nx-as，无主进程） | **别的应用做边车**：`FROM nx-as-base` + `ENV NXAS_TARGET_CMD`（见 nx-as-sidecar skill） |
| `full` | 默认产品形态（base + 内嵌 pi-web） | 单容器跑 pi-web 网关 |
| `gost` | **gost-as**（gost relay + nginx + nx-as 三进程） | 47 服务器部署形态（最常用） |

```bash
# 本地构建 gost-as（前端在构建内完成 npm run build——本地改前端不用预构建）
docker build --target gost -t gost-as:<版本> .
# base 边车镜像
docker build --target base -t nx-as-base:<版本> .
```

## 常见故障

| 症状 | 处置 |
|---|---|
| `alpine:3.20 manifest ... unexpected EOF`（镜像源瞬断） | `docker tag alpine:3.16.3 alpine:3.20` 顶替再建——gost-bin 阶段只解压静态二进制，alpine 版本无影响；其余层有缓存不受影响 |
| 构建里 `npm run build` 失败 | 先本地 `pnpm run build` 复现（多为前端语法/依赖问题） |

## 本地容器冒烟（发版前必做，曾拦下 stream 模块缺失）

```bash
docker rm -f gostas-smoke 2>/dev/null
docker run -d --name gostas-smoke --network host \
  -e NXAS_LISTEN_PORT=18090 -e NXAS_API_PORT=17801 \
  -e NXAS_GOST_PORT=18442 -e NXAS_GOST_INTERNAL_PORT=19442 \
  -e NXAS_OIDC_ISSUER=http://<go-ah> -e NXAS_OIDC_CLIENT_ID=nx-as \
  -e NXAS_OIDC_ALLOWED_EMAILS=<你的邮箱> \
  gost-as:<版本>
sleep 6 && docker logs gostas-smoke 2>&1 | grep -E 'gost-init|stream|就绪|emerg|FATAL'
# 预期：SSO 门槛通过 / stream 端口映射打印 / probe 四段 / 就绪，无 emerg
docker exec gostas-smoke netstat -tln | grep -E '18090|18442|19442'   # 19442 必须 127.0.0.1
docker rm -f gostas-smoke
```
