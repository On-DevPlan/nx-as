# B04 · 扩展点（加 action / 加模块 / 加隧道 / 加鉴权路径）

> 设计原则见 [[B03-交互模型]]：一切功能 = 一条 action；鉴权收敛在三个函数。这里给"加东西"的完整清单。

## 加一条 action（最常见，五步）

1. `src/modules/<域>/index.js` 声明 `{ id, cli, http, args, flags, run, render }`（http 可 null = 仅 CLI）
2. 业务写 `service.js`；action 只做编排（失败抛 `badInput/notFound/unauthorized` 错误码，业务结果返回 `{status}`）
3. args 名与路由占位符同名绑定（`args:['name']` + `/api/x/:name`）
4. **公开路径例外**：需要免鉴权访问 → 且仅当必要时改 `src/runtime/api.js PUBLIC_PATHS`（红线 4）
5. 登记：`assets/nx-as/SKILL.md` 命令表加行（`tests/unit/docs.test.mjs` 会扫所有 md 的 `nx-as xxx` 命令可解析性——没登记/命令拼错直接红）

## 加一个新模块（六处，漏一处静默）

```
src/modules/<域>/{index.js,service.js,view.jsx}   view 有则 tab 可见
src/index.js + src/modules/index.js               两处导出（漏 = ACTIONS 不含，纯静默）
src/runtime/registry.js MODULES                   模块注册表
src/web/frontend/registry.js VIEWS                前端 tab（与后端 view:true 对账测试）
eslint config 互依禁列                             加模块必须补一行，漏补是静默的
```

## 加一条隧道（红线 3：单一模板源）

用户入口是 `tunnel add`（BUILTINS，一条龙：配对→注册→常驻 gost）；它内部复用 client 域 `registerTunnel` 与 `core/gost-daemon.js`。**证书不再是独立模块**（`nginx cert import` 落盘后自动回填 `store.nginx.certPath/keyPath`，UI 表单直接可用——改证书逻辑动 `modules/nginx/cert.js`）。

**只改 `src/modules/nginx/tunnel.js`**（模板 + 校验），注册方（client 域 `registerTunnel`、`scripts/nxas-tunnel.mjs`）永远只调 `nginx.tunnelApply/Remove`。要改 conf 结构（如加 WebSocket 头、新 location）：改模板 → `tests/unit/nginx-tunnel.test.mjs` 锚点断言同步 → 线上既有 conf 用 re-apply 幂等刷新（`nx-as nginx tunnel apply <名> --public-port <P>`）。

## 鉴权扩展点（三个收敛函数，别散着写）

| 要做什么 | 改哪里 | 说明 |
|---|---|---|
| 新免鉴权路径 | `runtime/api.js` `PUBLIC_PATHS` | 唯一入口（红线 4） |
| 校验逻辑变（如加 IP 限制/多因子） | `runtime/session.js` `requireSession` | api.js 与 gateway 共用，一处改两面生效 |
| 网关决策变（节流键/短票/新凭据类型） | `runtime/gateway/check.js` `decide` | nginx auth_request 契约（204/401/403 + 头）不能动 |
| OIDC 流程变 | `runtime/oidc.js` | discovery 缓存"成功才缓存"；redirect_uri 构造保持 env 优先 |

## 依赖方向（eslint 强制，改包结构前默诵）

`core/`（不依赖上层）← `modules/`（互不依赖，共享下沉 core）← `runtime/`（编排）；
`web/frontend` 只准 import 组件/api client/模块 view；Node 侧禁 import .jsx。
