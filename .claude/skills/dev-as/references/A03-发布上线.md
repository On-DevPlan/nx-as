# A03 · 发布上线（gost-as 版本迭代）

> 管线：本地构建（A01）→ 流式传输 → compose 更新 → 重建 → 五项验证。全程只动 gost-as 一个容器，不碰服务器其他服务。

## 1. 传输镜像（CI 同款管线，绕开服务器拉镜像慢）

```bash
docker save gost-as:<新版本> | gzip -1 | ssh <服务器别名> "docker load"
```

## 2. 更新 compose 并重建（/opt/gost-as/docker-compose.yml）

```bash
ssh <服务器> "
sed -i 's|image: gost-as:<旧>|image: gost-as:<新>|' /opt/gost-as/docker-compose.yml
cd /opt/gost-as && docker compose up -d"
```

必填 env 已在位则不动；首次部署/新增配置见 [[B02-配置体系]] 的 compose 清单
（`NXAS_OIDC_ISSUER/CLIENT_ID/ALLOWED_EMAILS` 必填、`REDIRECT_URI` 公网必填、`NXAS_BIND_AUDIT_ALLOW` 守卫白名单）。

**容器重建不用恢复隧道 conf**：http.d 符号链接到数据卷（0.9.1 起）持久；nginx 模板自动从镜像刷新。

## 3. 五项验证（缺一不算发布完成）

```bash
ssh <服务器> "
docker logs gost-as 2>&1 | grep -E 'gost-init|probe|就绪|emerg' | head -8   # ① SSO 门槛+probe 四段+无 emerg
ss -tlnp | grep -E ':(8090|8442|18442) '                                    # ② 8442=nginx 公网 / 18442=gost 回环
docker logs gost-as --since 3m | grep bind-audit || echo '守卫安静 ✓'        # ③ bind 守卫
curl -s http://127.0.0.1:7801/api/auth/verify                               # ④ {valid:true,sso:true}
curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' http://127.0.0.1:7877/  # ⑤ 隧道 302 SSO
"
# 外部再抽一口：curl -o /dev/null -w '%{http_code}\n' http://<server>:8090/   # 302 = 链路活
```

## 4. 回滚

```bash
ssh <服务器> "sed -i 's|image: gost-as:<新>|image: gost-as:<旧>|' /opt/gost-as/docker-compose.yml && cd /opt/gost-as && docker compose up -d"
# 隧道 conf 级回滚：面板「配置文件管理器」备份还原，或 /data/nginx-backups/<名>.conf/ 里取时间戳
```

## 发布纪律

- 改了任何鉴权/网络相关代码：先 `pnpm test` 全绿（A04），再本地容器冒烟（A01），再发布
- 发布窗口避开自己正在用的隧道高峰（重建 10s 内 8442/隧道口闪断，本地 gost 自动重连）
- 发布后留档：版本号 + 五项验证结果（审计 `oidc.login`/`gost.bind_abuse` 顺带扫一眼）
