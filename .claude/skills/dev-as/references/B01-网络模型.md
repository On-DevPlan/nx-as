# B01 · 网络模型（gost-as 部署形态）

> 设计立场：**公网唯一暴露面 = nginx**。鉴权的意义在于"绕不过去"——任何进程直接绑公网端口都是破坏模型。

## 端口全景（47 服务器实测快照，0.10.2）

```
                         公网（0.0.0.0，全部 nginx）
  :8090 面板/登录 ──┐
  :7877 :7866 隧道 ─┼─ nginx（容器 gost-as，host network）
  :8442 relay 入口 ─┘   │ http 层：auth_request → SSO 会话校验
                       │ stream 层（L4）：:8442 → 127.0.0.1:18442
                       ▼
            127.0.0.1（容器内回环，公网不可达）
  :7801   nx-as serve（管理面/网关决策）
  :18442  gost relay 本体（NXAS_GOST_INTERNAL_PORT）
  :17877/:17866  gost rtcp bind（= 10000 + 公网口，随客户端注册）
```

- 隧道数据路径：`公网:L → nginx(auth_request SSO) → 127.0.0.1:1L(gost rtcp) → relay → 本地 gost → 本地服务:L`
- relay 准入 = gost 账号口令（`/data/gost-auth.env`）；数据面鉴权 = 隧道口的 auth_request。两层各管一段。

## 容器内三进程（docker/entrypoint-gost.sh 编排顺序）

1. `gost-init.mjs`：store 初始化 + **SSO 三要素硬门槛**（issuer/clientId/**allowedEmails** 缺一 exit 1；`NXAS_OIDC_ENFORCE=0` 逃生）
2. nginx 配置：envsubst 渲染 `gost-as.conf.template` → http.d；stream 段写 `/etc/nginx/stream.d/gost-relay.conf`
3. gost relay（回环）→ nx-as serve（回环 7801）→ 就绪探活 → probe 自检日志 → bind-audit 守卫循环 → nginx 前台

## 两个关键持久化机制

- **http.d 符号链接**：`/etc/nginx/http.d → /data/http.d`（数据卷）。隧道 conf 重建容器不丢；模板（*.template）每次启动从 `/app/nginx-templates/` 刷新（旧镜像模板不会盖掉新镜像修复）。
- **stream 主块来自包**：`nginx-mod-stream` 自带 `/etc/nginx/conf.d/stream.conf`（内含 `stream { include stream.d/*.conf; }`）。**别往 nginx.conf 追加 stream 块**（duplicate 起步）。

## bind 滥用与守卫（已知残留风险，必须知道）

gost relay `bind=true` 允许**凭据持有者**申请任意非回环端口（实测 `bindAddr` 参数无效、gost v3.2.6 无白名单）——这是绕过 nginx 鉴权的裸穿透向量。防线两道：

1. **bind-audit 守卫**（`docker/bind-audit.mjs`，entrypoint 每 60s 调用）：扫 `/proc/net/tcp(+tcp6)` LISTEN，非回环、不在 nginx conf 声明端口集、不在 `NXAS_BIND_AUDIT_ALLOW` 白名单 → stderr 告警 + 审计 `gost.bind_abuse`。**新增公网合法端口的正确姿势**：进 nginx conf（自动被收集）或加进 compose 的 `NXAS_BIND_AUDIT_ALLOW`。
2. **安全组收敛**（阿里云控制台，人工）：白名单放行已知端口；临时端口按需开。这是最硬的一层闸。

## 验证命令（改网络模型后必跑）

```bash
# 服务器上：端口归属（公网应全 nginx，gost 只在 127.0.0.1）
ssh <server> "ss -tlnp | grep -E ':(8090|8442|18442|<隧道口>) '"
# 守卫状态与审计
docker logs gost-as --since 5m | grep bind-audit
docker exec gost-as tail -5 /data/audit.jsonl
# 外部三态：未登录 302 / 带会话非 401 / 伪造会话拒
curl -o /dev/null -w '%{http_code} %{redirect_url}\n' http://<server>:<端口>/
```

## 错误案例（真实）

| 坑 | 后果 | 预防 |
|---|---|---|
| alpine nginx 无 stream 模块就直接发版 | 容器起不来（unknown directive） | 本地容器冒烟先行（04 的发布流程含此步） |
| 往 nginx.conf 追加 stream{} | duplicate 报错 | stream 主块用包自带的，只写 stream.d server |
| gost 绑 `:8442` 全接口 | relay 直接暴露公网 | relay 只绑 `127.0.0.1:$NXAS_GOST_INTERNAL_PORT` |
| 新公网端口没进守卫白名单 | 告警噪音/真告警被淹没 | 端口落地方式二选一：nginx conf 或 BIND_AUDIT_ALLOW |
