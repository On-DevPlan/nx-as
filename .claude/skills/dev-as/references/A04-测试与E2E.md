# A04 · 测试与 E2E（改代码后怎么验）

> 三层验证：**单测/冒烟（本地假 IdP，必跑）→ nginx 模式回归 → 真实线上 E2E（手动）**。改鉴权/网络相关代码，第一层不过不许提交。

## 第一层：本地全量（假 IdP，零外呼）

```bash
pnpm test   # = eslint + vite build + smoke + nginx-mode 回归 + 全部单测
```

| 部分 | 覆盖 | 关键文件 |
|---|---|---|
| smoke | serve 起真进程 + 假 IdP：登录→会话→短票→登出 全链 | `tests/smoke.mjs` |
| nginx-mode | `/_nxas` 前缀全链（redirect_uri 前缀/委托端点/静态页） | `tests/nginx-mode.test.mjs` |
| 单测-oidc | state 重放拒/错 verifier 拒/白名单 403/CLI handoff/rotate 全端下线 | `tests/unit/oidc.test.mjs` |
| 单测-gateway | 会话签发校验（Bearer=cookie 等价）/短票/节流 | `tests/unit/gateway.test.mjs` |
| 单测-tunnel | conf 模板锚点（鉴权三要素）+ 管线（-t 失败还原） | `tests/unit/nginx-tunnel.test.mjs` |
| 单测-bind-audit | /proc 小端序解析/v6 归一/nginx 端口收集/越权告警 | `tests/unit/bind-audit.test.mjs` |

**假 IdP**：`tests/helpers/fake-idp.mjs`（本地 http 起 discovery/authorize/token/userinfo，PKCE/一次性 code/回环通配语义与 go-ah 对齐）。新鉴权用例一律用它，不打真 IdP。

## 第二层：nginx 模式（含在 pnpm test 里）

改了 `/_nxas` 相关路由/模板/前缀逻辑时重点看它——登录循环类 bug 只在这里现形（`/_nxas/login → /_nxas/oidc/login` 前缀断言）。

## 第三层：真实线上 E2E（手动，发布后跑）

```bash
node tests/e2e-live.mjs
# 19 断言：go-ah 真实登录 → 面板 SSO 全链 → 会话身份 → 隧道注册 →
#         双端口三态鉴权（未登录 302 / 带会话放行 / 伪造拒）→ server conf 对账
```

- 脚本头部有真实账号密码依赖——按需改或从 env 读；**不要进 CI**
- 隧道注册断言是幂等的（重复跑只对账）

## 定位技巧

| 症状 | 先看 |
|---|---|
| 会话 401 但登录成功 | `session.js verifySessionCookie`（正则捕获组解构曾错位）；`curl -H Cookie:... /_nxas/api/auth/me` |
| 登录页无限跳 | `/_nxas` 前缀是否在每一跳都保留（server.js 分发 + session.js 错误页链接） |
| 隧道 502 | server 侧 rtcp bind 是否活着（`docker logs gost-as | grep 'bind on'`）+ 本地 gost 常驻 |
| 告警噪音 | `NXAS_BIND_AUDIT_ALLOW` 是否漏了宿主既有端口 |
| **面板白屏**（root 空、JS/CSS 200、无跳转） | 浏览器 console 的运行时错误——lint/单测都抓不到组件作用域类 bug（真实案例：`{me?.email}` 写在了状态所在的 AuthGate 组件之外 → ReferenceError → React 整树崩溃）。**改 `src/web/frontend` 后必须浏览器实测渲染**，curl 只能验资源 200 |
