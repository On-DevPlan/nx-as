# B03 · 交互模型（action 双端 + SSO 会话流）

> 一句话：**一切功能 = 一条 action**（CLI 命令与 HTTP 路由同源）；**人的凭据 = 一个会话**（cookie 与 Bearer 同一 token）。

## action 双端声明（唯一功能入口）

```js
// src/modules/<域>/index.js
{ id: 'nginx.tunnelApply', cli: ['nginx', 'tunnel', 'apply'],
  http: ['POST', '/api/nginx/tunnel'],            // http: null = 仅 CLI（如 oidc register 管理员凭据）
  args: [{ name: 'name', required: true }], flags: { 'public-port': { type: 'number', required: true } },
  run: (ctx) => upsertTunnel({...}),              // 业务只写 service；ctx 自动合并 路径占位/query/body
  render: (r) => `人类可读输出`, }
```

- 汇总链：各模块 index.js → `src/index.js` ACTIONS → `runtime/api.js` 编译路由（HTTP 面）+ `runtime/cli.js`（CLI 面）。registry.js 装载期自检（id/cli 重复、缺 run、路由冲突）启动即报。
- **CLI 是进程内直跑**（不走 HTTP）——本地命令天然免鉴权；需要凭据的是 HTTP 面（面板/远程 client 域）。
- 新公开路径只能进 `api.js PUBLIC_PATHS`（当前 verify/bootstrap 两条，见红线 4）。

## SSO 会话流（人的凭据生命周期）

```
浏览器 → /login(兼容别名) 或 /oidc/login?next=
       → 302 go-ah /oauth2/auth（state + PKCE S256 装进签名短时 cookie nxas_oidc 10min）
       → go-ah 登录/同意 → 302 /oidc/callback?code&state
       → back-channel 换 token → /oauth2/userinfo 取身份（sub/email/name）
       → 白名单比对（生效值）→ 签会话 nxas_s2.<b64payload>.<HMAC>（7 天）
       → Set-Cookie（HttpOnly/SameSite=Lax；https 反代时 +Secure）+ pi-web 会话 bootstrap 代签
       → 302 next（站内相对路径）或 cli 回环地址（仅 127.0.0.1，带 ?token=）
```

- 会话校验唯一入口：`runtime/session.js requireSession(req)`——Bearer 头优先、cookie 次之；`api.js authorized()` 与 `gateway/check.js decide()` 都调它。
- 面板（AuthGate）：`/api/auth/me` 401 → 整页跳 `/_nxas/oidc/login`；api client 显式 `credentials:'same-origin'`。
- 刷新令牌**不落地**（go-ah 平台硬约束）：过期重新 302，IdP 全局会话 30 天内无感。

## client 域配对（本地 ↔ 远程）

`nx-as client login [--server <url>]` / 面板「配对登录」按钮 → `core/sso-handoff.js ssoHandoff`：本机随机回环口起一次性监听 → 开浏览器 `<server>/oidc/login?cli=http://127.0.0.1:<port>/done` → 登录完成服务器 302 回传会话 token → `credentials.json` 落盘（`rememberCredential`，server 归一化匹配忽略 `/_nxas` 后缀差异）。此后 client 域 serverApi/doctor/tunnel 注册自动带凭据——**没有独立 token**。

## 网关面与委托（nginx 模式契约）

`/_nxas/auth/check` 是 nginx `auth_request` 委托端点：204+`X-Device-Id`/`X-Auth-Cred` 放行、401（浏览器由 nginx `error_page → @nxas_login → /_nxas/login` 接管跳 SSO）、403+Retry-After（节流）。SSE 用一次性短票（`gateway/tickets.js`，60s、会话绑定、单次消费）。改鉴权语义时**契约不能动**（旧 nginx conf 还在线上引用）。

## 排查路径（交互层）

```bash
nx-as oidc probe                     # 四段一致性（discovery/client/whitelist/生效回调）
nx-as auth me [--token]              # 当前身份（Bearer 载体验证）
docker logs gost-as | grep -E 'probe|bind-audit|oidc'   # 启动自检 + 登录审计
curl -H "Cookie: nxas_session=<t>" http://<server>/_nxas/api/auth/me
```
